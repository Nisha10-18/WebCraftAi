# 🤖 WebCraft AI

WebCraft AI is an AI-powered website generation platform that transforms natural language prompts into modern, responsive websites. Simply describe the website you want, choose the website type, framework, and theme, and let the AI generate the website for you.

The application provides a clean and premium user interface along with a live preview experience, making website generation simple and interactive.

---

## Features

- AI-powered website generation
- Premium modern UI with Black & Gold theme
- Natural language prompt input
- Multiple website categories
- Framework selection (React, Next.js, HTML/CSS, Vue)
- Multiple design themes
- Live website preview
- Responsive design
- Fast generation workflow
- Spring Boot backend integration

---

## How It Works

1. Enter your website idea.
2. Select the website type.
3. Choose the framework.
4. Select a design theme.
5. Click **Generate Website**.
6. The AI generates the website.
7. Preview the generated website directly in the application.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/your-username/webcraft-ai.git
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
mvn spring-boot:run
```
